# استخراج اقلام به اکسل (Android / Kotlin)

برنامه با **Accessibility Service** صفحه‌ی «حذف اقلام فروشگاهی» را تشخیص می‌دهد، یک دکمه‌ی شناور نشان می‌دهد و با زدن آن:

1. لیست را به بالا برمی‌گرداند،
2. با اسکرول خودکار همه‌ی کارت‌ها را می‌خواند (نام، بارکد، موجودی، درصد ضایعات، قیمت، توضیح)،
3. تکراری‌ها را بر اساس بارکد حذف می‌کند،
4. فایل `items_تاریخ.xlsx` را در `Download/ItemExporter` می‌سازد.

## ساخت
1. پوشه را در **Android Studio** (Koala یا جدیدتر) باز کنید و Sync کنید.
2. Build ▸ Build APK یا Run روی گوشی (Android 10 به بالا).

## استفاده
1. برنامه را باز کنید ▸ «باز کردن تنظیمات دسترسی‌پذیری» ▸ سرویس را روشن کنید.
   (اگر اندروید ۱۳+ بود و گزینه خاکستری بود: App info ▸ ⋮ ▸ Allow restricted settings)
2. برنامه فروشگاهی ▸ صفحه «حذف اقلام فروشگاهی».
3. دکمه صورتی «⬇ استخراج اکسل» ظاهر می‌شود. بزنید. (دوباره بزنید = توقف و ذخیره)

## عیب‌یابی
اگر ستونی خالی یا اشتباه بود، دکمه را **لمس طولانی** کنید؛ ساختار صفحه در
`Download/ItemExporter/dump_*.txt` ذخیره می‌شود. محتوای آن را بفرستید تا پارسر (`Parser.kt`) دقیق‌تر شود.

## حالت خواندن فوری
با زدن دکمه، ابتدا همه‌ی نودهایی که برنامه از قبل لود کرده (حتی بیرون از صفحه) در یک مرحله و بدون اسکرول خوانده می‌شود.
اگر تعداد خوانده‌شده با «تعداد:» بالای صفحه برابر باشد، همان‌جا فایل ساخته می‌شود؛ در غیر این صورت (مثلاً اگر برنامه کارت‌های بیرون از صفحه را در حافظه نگه نمی‌دارد) خودکار به حالت اسکرول می‌رود.

## ساخت خودکار APK با GitHub Actions
1. کل پوشه (با `.github/workflows/main.yml`) را در یک مخزن GitHub بگذارید و روی شاخه‌ی `main` push کنید.
2. تب **Actions** ▸ «Build Android APK» ▸ پس از پایان، APK را از بخش **Artifacts** دانلود کنید.
3. اگر بیلد خطا داد، گزارش در Artifact با نام `build-reports` ذخیره می‌شود. متن خطای Step «Build debug APK» را بفرستید.
